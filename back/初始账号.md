## 🚀 使用方法

### 初始化账号

执行数据库迁移后，运行种子脚本创建初始账号：

```bash
cd back
npm run prisma:seed
```

### 登录系统

1. 启动后端服务：
   ```bash
   npm run dev
   ```

2. 启动前端服务：
   ```bash
   cd ../front
   npm run dev
   ```

3. 访问 `http://localhost:5173`

4. 使用上述任一账号登录测试不同角色的权限

## 🔐 安全建议

⚠️ **重要提示：**

1. **生产环境必须修改密码**
   - 这些账号仅用于开发和测试
   - 部署到生产环境前必须修改所有初始密码

2. **修改超级管理员账号**
   - 建议修改超级管理员的用户名
   - 使用强密码（至少包含大小写字母、数字和特殊字符）

3. **定期更换密码**
   - 建议每3个月更换一次管理员密码
   - 可在个人中心进行密码修改

4. **删除测试账号**
   - 生产环境上线前删除不需要的测试账号
   - 保留必要的管理员账号即可

## 🔄 重置账号

如果需要重置初始账号，可以：

1. **删除特定用户:**
   ```bash
   # 使用 Prisma Studio
   npm run prisma:studio
   # 在浏览器中打开，找到 users 表，删除对应用户
   ```

2. **重新运行种子脚本:**
   ```bash
   npm run prisma:seed
   ```

3. **完全重置数据库:**
   ```bash
   npm run prisma:migrate reset
   # 注意：这会删除所有数据！
   ```
